# Jenkins ORAS Java SDK API Plugin

Jenkins ORAS Java SDK API Plugin.

## Build and test

- Run `mvn -Dset.changelist clean verify` from the repository root.
- Follow the existing Jenkins plugin conventions and avoid unrelated changes.

## Pull requests

- Check the repository's `.github/pull_request_template.md` first; if absent, use the shared `jenkinsci/.github` template.
- Open pull requests against `jenkinsci/oras-java-api-plugin` from a topic branch based on upstream `main`; use the `documentation` label for documentation-only changes.
